一句话结论

方向对，量级存疑：NPO 这套"傻瓜式"prompt 优化循环确实便宜好用、能涨分，但小预算下涨幅小到接近噪声；而且它学到的最大一部分改进，居然是"让模型闭嘴只说答案"。

这篇论文在反谁

2026 年 prompt 优化赛道在卷复杂度：GEPA 用种群+Pareto 支配做 prompt 进化搜索，一套流程比强化学习还讲究。Purdue 这篇论文说：没必要。他们提出 NPO——拿一个教师模型，看学生最近几轮的完整答题轨迹和得分，然后改写 prompt。单条血脉、线性迭代、没有任何搜索。结果：rollout 更少，效果不输 GEPA，教师越强优势越大。

这种"反过度工程"的论文，最该做的事是复现。可惜作者没放代码——GitHub 全站检索不到任何引用这篇 arXiv id 的仓库。我们决定自己跑一遍。

我们怎么跑的

完全按论文算法 1 逐步实现：HotpotQA 多跳问答，学生模型 deepseek-chat，教师模型 deepseek-reasoner（对应论文"更强教师"档），固定 60 例不相交验证集，EM/F1 用 HotpotQA 官方归一化。预算从论文的 6,800 rollouts 砍到 32（成本 <¥5）。

结果：baseline prompt EM 0.300 → NPO 最佳候选 EM 0.333（+3.3pt），两次独立运行方向一致（另一次 +6.7pt）。

三个论文没告诉你的毛边

1. 优化器会静默坏掉。 DeepSeek-reasoner 的思考链吃光 max_tokens 时，正文返回空串——不加守卫，NPO 会拿"空 prompt"当候选继续跑，曲线悄悄崩掉。论文完全没讨论优化器失效路径。

2. 小预算下信号被方差淹没。 60 例验证集的标准误约 ±6pt，我们 +3.3pt 的提升在噪声边缘。论文里漂亮的收敛曲线是用 6,800 rollouts 换来的——换句话说，这个方法的效果和它的成本一样，都是真金白银堆出来的，别被"naive"俩字骗了。

3. 最有价值的一课是免费的。 教师模型迭代到第 3 轮，自己收敛出一条极简 prompt："只输出一行 Answer: xxx，不许推理、不许外部知识、必须锚定上下文"。测试发现这一条格式约束本身就值 2~3 个点。你不用跑优化循环，直接抄这条 prompt 就行。 这也解释了 NPO 增益里有多少是真"能力提升"、多少只是"输出规整"——论文 3.4 节专门自查"prompt 是否泄漏答案"，说明作者心里也打鼓。

该不该用 NPO

该。它是目前性价比最高的 prompt 优化基线：150 行代码、任何 API key 都能跑、没有 GEPA 那套基建。但设好预期：¥5 预算买方向，¥100+ 预算才买论文级涨幅。以及永远记住——优化器学到的"最好的 prompt"，经常只是教会模型好好说话，而不是变聪明。
