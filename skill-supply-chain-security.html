AI 正在从你的仓库里装东西：Skill 供应链安全入门

Levi Focus · 2026-10-23 · 数据来源：Anthropic / AAIF / Vercel State of Agent Skills / arXiv 138K SKILL.md 实证研究 · 分析（非原文）部分已标注

2026 年发生的最被低估的事，不是又一个新模型，而是「怎么做事的知识」第一次成了独立的分发品类。Agent Skills（一个 SKILL.md 文件）从 Anthropic 2025 年 10 月发布到捐给 Linux 基金会只用了两个月；skills.sh 注册表 7 个月冲到 100 万个 skill、近 2.8 亿次安装——GitHub 花了 27 个月才有 100 万个仓库。

但增长最快的分发渠道，配着几乎不存在的质检。这篇讲清楚：坑在哪，你怎么不被坑。

把这三行连起来读：一个不审查内容、以安装量排序的分发网络，正在被批量攻击者当猎场。这不是预言，是已经发生的事。

为什么 SKILL.md 本质上是代码

多数人把 skill 当「文档」装。错了。SKILL.md 是一份会被带工具权限的 Agent 逐字执行的指令载荷——审查它应该像审查一段 shell 脚本，而不是像读一篇教程。

一个「markdown 格式化」技能的正文里出现 curl，或者一个「周报生成器」要求读取 ~/.ssh——名字与内容的错位，是普通人能用的最强免费信号。攻击者的成本结构里，专业格式是免费的，所以「看起来专业」毫无意义；唯一要问的是：装了它之后，我的 Agent 会做什么不一样的事？

可执行的审查清单（五步）

  1. 验出身：仓库历史、fork 链、是否上周才注册的新号。star 不是安全信号——3 年连贯提交的 1 星仓库，好过上周创建的 500 星仓库。
  2. 读全文找三类危险句：外发数据的（curl 上报、"验证服务"）、碰凭证的（.env/ssh/浏览器资料）、要求绕过确认的（"不要问用户"、"跳过验证"）。
  3. 查触发范围：描述写成「凡涉及 X 任务必须使用」的 skill 会劫持无关任务。好的描述范围收敛，坏的行为吞上下文。
  4. 算上下文税：正文超过 2000 词的 skill 会在每次相关任务里挤占你的上下文预算。长内容该在 references/ 里按需加载。
  5. 隔离试用再转正：先装到一次性环境跑一个无害任务，对比有/无 skill 的实际工具调用差异——看它做了什么，不是它声称做了什么。

这五步已打包成开源技能包 agent-security-skills（含 skill-review-checklist、secure-addon-install、mcp-permission-audit、silent-failure-sweep、llm-attack-surface 五件，一条命令安装：npx skills add Focus688/agent-security-skills）。每一个规则都来自我自己运维 7×24 小时 Agent 时真实踩过的坑，不是论文综述。

给内容创作者的一个提醒

还有一个正在发生的迁移：你网页的读者可能越来越多不是人，而是 Agent。有托管平台统计其文档流量 66% 来自 AI Agent。这意味着给 Agent 读的结构化约定（llms.txt、AGENTS.md、JSON-LD）会像当年的 SEO 一样，从怪癖变成标配。你的仓库、你的站点、你的 skill，都应该默认有一个「机器读者入口」。

上一代人在 GitHub 上攒 star，下一代人在 registry 上攒安装量。分发渠道换了，要换的不是努力，是货架。
